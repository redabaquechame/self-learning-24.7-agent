# Optional human submission verification core

Candidate SC-2F implementation, unaccepted. One independent review and final current regression are required. Local synthetic records and synthetic reviewer-role fixtures are not actual subject review, human learning or installed qualification.

`LearningService(human_assessment=...)` consumes a host-created `HumanAssessmentAuthority` over `AttemptCustody`. Default services retain the reserved assessment operation and unscored digest-only legacy submissions. All four adapters use the same service. The ingress method verifies the host binding and attempt entitlement; an arbitrary digest or frontend-selected expected result, evaluator, score, identity or qualification cannot create a human submission/verdict.

Custody uses owner-controlled `org/tutor-human-submissions`, a host-supplied key of at least32bytes, scoped immutable metadata and exact UTF-8 JSON blobs. Snapshot bytes are limited to256KiB,20levels and10,000nodes; duplicate keys/nonfinite values and executable/archive formats refuse. An attempt admits at most8 distinct artifacts; this first mechanical evaluator accepts exactly one. After submission, later upload/replacement refuses. Every evaluation/replay rechecks signed scope, submitted bytes, current exact rubric/pack and exposure. This detects tampering; it is not operating-system containment or at-rest encryption.

The closed evaluators are canonical JSON equality and grouped numeric output. Group sums use decimal arithmetic, at most1,000rows, magnitude at most10^12 per input and at most8 fractional places. JSON booleans cannot masquerade as numeric answers. Group output order and equivalent numeric representations are accepted; expected amounts are not returned. Unsupported code, spreadsheet/formula, archive and subjective families remain unavailable.

Fractional JSON literals are decoded directly as exact decimal values. Canonical number identity removes equivalent formatting without binary-float conversion or context rounding; booleans remain distinct. Grouped output supports aggregate magnitude10^15 while retaining the per-input10^12 boundary. Raw-byte eighth-place differences at large magnitudes are checked both directly and through reviewed-reference loading.

Production rubric loading requires current independently reviewed/qualified pack state, an exact hidden assessment-manifest reference and the digest of the bytes actually loaded. A locally constructed engineering rubric remains LOCAL_ONLY: its predicate can be observed, but passing stays null and independent success false. The synthetic-role fixture exercises the existing review permission mechanism only; it does not supply actual expert content review to this build.

Exposure facts come from the host. UNKNOWN coverage creates no independent credit. Agent/shared/answer/hint/execution/repeated-example evidence disqualifies independence. An allowed accommodation does not by itself count as answer exposure. Recorded-condition eligibility is bounded to those conditions, not a claim that screen observation proves absence of outside assistance. Later changed exposure refuses reusing a verdict until the correction lifecycle is implemented.

Initial exposure is sealed into the attempt before issuance. A signed append-only exposure chain records bounded distinct host facts at begin/ingest/submit/evaluate and through `record_human_exposure` before help is published. Merging retains every known answer/assistance/repeated-example and unknown-coverage fact; later clean snapshots cannot erase them. At most64distinct facts are accepted. The current custody instance anchors its observed chain head and refuses truncation/deletion/change. Cross-restart anti-rollback/head recovery is not qualified; host reconstruction and durable verdict projection remain release prerequisites. Complete coverage is an explicit host-policy assertion about recorded conditions; missing publication telemetry must remain UNKNOWN.

The grader invokes no goal pursuit, legacy agent evaluator, provider, source-document repair or submitted-artifact write. Incorrect work remains incorrect. Local failure/retry uses the same original bytes. In-process concurrent or differently keyed assessments return one shared verdict record/lineage. Original agent mastery remains a separate existing path.

Current readback revalidates attribution separately from immutable original judgment. New ANSWER/UNKNOWN exposure or unavailable custody/rubric marks the public projection REVIEW_REQUIRED, clears current passing/independent credit and labels the retained original judgment. Attempt state is invalidated through the host publication hook; reevaluation/replay refuses stale attribution. Readback appends no exposure or correction record. This conservative projection is not a completed appeal/correction lifecycle. Cancelled attempts cannot ingest more artifacts; a second explicitly authorized assessor shares the original verdict lineage.

Host key provisioning, restart/job recovery and durable verdict projection, native upload/assessment UX, broader evaluator families, qualified content/human evidence, appeals/correction/export/deletion and institutional/retention/rights lifecycle remain mandatory. The service does not advertise those missing operations as successful. Production owner/provider/Fleet discovery, actual source geometry/visible guidance and all other retained packets also remain open.
